OpenFactory Virtual Factory
Prototype App
Personalized production workflow

Design a custom liquid product order.

This OpenFactory app converts a user-defined product request into a first virtual recipe and production sequence for a personalized liquid production line.

What this prototype does

1
User creates a product order
The customer chooses a target color, bottle volume, and label text.
2
App computes the recipe
RGB and volume are converted into red, green, blue, and base liquid quantities.
3
Virtual work order is generated
The order is translated into a production sequence for the future factory.

Create product order

Select the personalized liquid product parameters.

No physical hardware is controlled yet. This first version creates the virtual product recipe and work order.
